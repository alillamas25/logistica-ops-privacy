Logistica Ops Dashboard

Política de Privacidad

Última actualización: 30 de septiembre de 2026

1. Alcance y estado del proyecto

Logistica Ops Dashboard es un proyecto personal e interno en desarrollo y pruebas. Esta política describe de forma proporcional cómo podría tratarse la información durante una prueba técnica de integración.

2. Finalidad

La finalidad es evaluar técnicamente una integración con WhatsApp Business Platform para recibir y procesar mensajes mediante webhooks, así como realizar pruebas, diagnóstico y evaluación técnica de la aplicación.

3. Datos que podrían procesarse

Cuando se utilice la integración, podrían procesarse únicamente los datos técnicos necesarios para la prueba:

  • identificador técnico del mensaje;
  • identificador del remitente proporcionado por la plataforma;
  • fecha y hora asociadas al mensaje;
  • tipo de mensaje;
  • contenido textual cuando sea necesario para la prueba;
  • fecha y hora de recepción técnica.

No se pretende recopilar categorías adicionales de datos que no sean necesarias para esta evaluación técnica.

4. Uso de la información

La información se utilizaría únicamente para operar la prueba, verificar el funcionamiento del webhook, diagnosticar errores y evaluar técnicamente la integración. No se venden datos personales ni se utilizan para publicidad dirigida.

5. Conservación y eliminación

Los datos de prueba se conservarán únicamente durante el tiempo necesario para realizar las pruebas y el diagnóstico. Cuando dejen de ser necesarios para estos fines, podrán ser eliminados. Las solicitudes relacionadas con eliminación de datos pueden realizarse a través del correo de contacto indicado en esta política.

6. Seguridad

Se procura aplicar medidas razonables para limitar el acceso, minimizar los datos tratados y mantener la información de prueba en entornos controlados. Ninguna medida técnica puede garantizar seguridad absoluta.

7. Servicios de terceros

La prueba puede utilizar servicios y plataformas de Meta/WhatsApp para la transmisión técnica de eventos. Esto no implica afiliación, patrocinio ni representación de Meta o WhatsApp.

8. Consultas y solicitudes sobre datos

Para realizar consultas sobre esta política o solicitar información relacionada con los datos de la POC, puede escribirse a citalli.pidedirecto@gmail.com.

Las solicitudes se atenderán de manera razonable considerando el carácter experimental y limitado del proyecto.

Este documento es una descripción informativa de una POC en desarrollo y no constituye asesoría jurídica.
